STRATEGIES IMPLEMENTED (4 total):
  1. Covered Call
     ├─ Long stock + Short call
     ├─ Best for income generation
     └─ Limited profit, limited loss

  2. Protective Put
     ├─ Long stock + Long put
     ├─ Best for hedging
     └─ Limited loss, unlimited profit

  3. Bull Call Spread
     ├─ Long call + Short call
     ├─ Best for bullish bets
     └─ Limited profit and loss

  4. Iron Condor
     ├─ Short call spread + Short put spread
     ├─ Best for neutral outlook
     └─ Limited profit and loss

CALCULATIONS (for each strategy):
  ├─ Maximum Profit
  ├─ Maximum Loss
  ├─ Breakeven points (1-2)
  ├─ Entry cost
  ├─ Return percentage
  ├─ Risk/Reward ratio
  └─ Exit price indicator

INSTALLATION SUMMARY
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Setup Project
  Command: python setup.py
  Creates: src/ directory with React files

STEP 2: Install Python Dependencies
  Command: pip install -r requirements.txt
  Installs: FastAPI, Uvicorn, httpx, numpy, pandas, etc.

STEP 3: Install Node Dependencies
  Command: npm install
  Installs: React, Vite, Axios, etc.

STEP 4: Configure API
  File: .env
  Content: POLYGON_API_KEY=your_key_here

STEP 5: Run Backend
  Command: python main.py
  Starts: FastAPI server on http://localhost:8000

STEP 6: Run Frontend
  Command: npm run dev
  Starts: React dev server on http://localhost:3000

STEP 7: Access Application
  URL: http://localhost:3000
