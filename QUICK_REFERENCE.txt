📋 INSTALLATION (Copy & Paste)
════════════════════════════════════════════════════════════════════════════════

# 1. Setup project directory
python setup.py

# 2. Install dependencies (both at same time or separate)
pip install -r requirements.txt
npm install

# 3. Create .env file (copy the template)
copy .env.example .env
# Then edit .env and add: POLYGON_API_KEY=your_api_key_here

💡 QUICK USAGE
════════════════════════════════════════════════════════════════════════════════

1. Enter stock symbol (e.g., SPY, AAPL, TSLA)
2. Select expiration date from dropdown
3. Click "Backtest Strategies"
4. View 4 strategy cards with metrics
5. Check comparison table for side-by-side analysis


📊 WHAT YOU'LL SEE
════════════════════════════════════════════════════════════════════════════════

For each strategy:
  • Entry Cost - Initial capital needed
  • Max Profit - Best-case scenario
  • Max Loss - Worst-case scenario
  • Return % - (Max Profit / Entry Cost) × 100
  • Risk/Reward - Max Profit / Max Loss
  • Breakeven - Stock price(s) where P&L = 0


🎨 STRATEGY TYPES
════════════════════════════════════════════════════════════════════════════════

1. COVERED CALL
   Long Stock + Short Call
   🟢 Income generation
   → Max Profit = Strike - Cost
   
2. PROTECTIVE PUT
   Long Stock + Long Put
   🟢 Downside protection
   → Max Profit = Unlimited
   
3. BULL CALL SPREAD
   Long Call + Short Call (higher)
   🟢 Bullish with limited capital
   → Max Profit = Spread Width - Cost
   
4. IRON CONDOR
   Short Call Spread + Short Put Spread
   🟢 Neutral outlook, defined risk
   → Max Profit = Credit Received

🐛 COMMON ISSUES
════════════════════════════════════════════════════════════════════════════════

❌ "No module named fastapi"
   ✓ Run: pip install -r requirements.txt

❌ "Connection refused"
   ✓ Make sure backend is running: python main.py

❌ "Cannot find module react"
   ✓ Run: npm install

❌ "POLYGON_API_KEY error"
   ✓ Check .env file has correct API key

❌ "Port 3000 already in use"
   ✓ Kill the process or change port in vite.config.js

❌ "Port 8000 already in use"
   ✓ Kill the process or change port in main.py
