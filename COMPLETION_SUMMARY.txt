📊 STRATEGIES IMPLEMENTED
════════════════════════════════════════════════════════════════════════════════

1. COVERED CALL
   ├─ Position: Long stock + Short call
   ├─ Best for: Income generation
   ├─ Max Profit: Strike - Entry cost
   ├─ Max Loss: Entry cost
   └─ Use: Conservative income strategy

2. PROTECTIVE PUT
   ├─ Position: Long stock + Long put
   ├─ Best for: Downside protection
   ├─ Max Profit: Unlimited
   ├─ Max Loss: Entry cost - Put strike
   └─ Use: Defensive hedging strategy

3. BULL CALL SPREAD
   ├─ Position: Long call + Short call (higher strike)
   ├─ Best for: Bullish with limited capital
   ├─ Max Profit: Spread width - Cost
   ├─ Max Loss: Entry cost
   └─ Use: Defined-risk bullish strategy

4. IRON CONDOR
   ├─ Position: Short call spread + Short put spread
   ├─ Best for: Neutral outlook
   ├─ Max Profit: Credit received
   ├─ Max Loss: Spread width - Credit
   └─ Use: High probability, defined-risk strategy

🚀 QUICK START (5 MINUTES)
════════════════════════════════════════════════════════════════════════════════

1. Create src directory:
   python setup.py

2. Install dependencies:
   pip install -r requirements.txt
   npm install

3. Configure API key:
   copy .env.example .env
   # Edit .env and add POLYGON_API_KEY

4. Start backend (Terminal 1):
   python main.py
   → Runs on http://localhost:8000

5. Start frontend (Terminal 2):
   npm run dev
   → Runs on http://localhost:3000

6. Open browser:
   http://localhost:3000

🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

"Module not found"
  → pip install -r requirements.txt && npm install

"Connection refused"
  → Make sure backend running: python main.py

"POLYGON_API_KEY error"
  → Check .env file has correct key

"No options found"
  → Symbol may not have options or date doesn't exist

"Port in use"
  → Change port in vite.config.js or main.py
